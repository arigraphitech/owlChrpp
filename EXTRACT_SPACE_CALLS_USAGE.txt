USAGE:
  ./extract_space_calls.sh <ontology_file> [output_dir]

EXAMPLES:
  # Extract space_calls.txt from OWL2RL-10.ofn to current directory
  ./extract_space_calls.sh results/OWL2RL-10.ofn

  # Extract and save to specific directory
  ./extract_space_calls.sh results/OWL2RL-10.ofn ./my_output

WHAT IT DOES:
  1. Compiles extract_space_calls executable (if needed)
  2. Parses the OWL ontology using parsercowl_spacecalls.h
  3. Generates space_calls.txt with all space-> method calls
  4. Logs axiom processing to stderr
  5. Saves output to the specified directory

OUTPUT FORMAT:
  space_calls.txt contains executable CHR++ code:
    - Logical variable declarations
    - space-> method calls for each axiom
    - Comments showing axiom numbers and OWL text

PERFORMANCE:
  - First compilation: 1-2 minutes
  - Parsing time: Varies by ontology size
  - Output size: ~2.5 MB for OWL2RL-10

FILES GENERATED:
  - ./build_spacecalls/extract_space_calls (executable)
  - ./build_spacecalls/owlExtractSpaceCalls.cpp (generated C++)
  - <output_dir>/space_calls.txt (final output)

KEY FEATURES:
  ✓ Uses parsercowl_spacecalls.h for instrumentation
  ✓ No realisation/classification overhead
  ✓ Automatic absolute path handling
  ✓ Comprehensive error messages
  ✓ Multi-build support (reuses existing build if available)

REBUILDING:
  To force recompilation: rm -rf build_spacecalls
  Then run: ./extract_space_calls.sh <ontology_file> <output_dir>

For detailed documentation, see: EXTRACT_SPACE_CALLS.md
